1. Overview & Tóm tắt nâng cấp

Reader App là sản phẩm đọc truyện chữ (web-novel / e-book) tiếng Việt tự host nội dung, gồm 3 tầng đã tồn tại:

  • Mobile: React Native 19.1.0 + Expo SDK 54 (Android).
  • Backend: Express.js monolith (admin-dashboard/server/index.js ~3200 dòng).
  • Admin Dashboard: React 18.2.0 + Vite.

Tài liệu này chuẩn hóa toàn bộ vòng đời sản phẩm, bảo vệ tiền tệ và hệ thống ở Phase 1, chuẩn hóa CSDL và phân rã monolith ở Phase 2, đồng thời bổ sung 2 trụ cột ở Phase 3:

  • Hệ thống Dual-Agent (MySQL): Agent 1 Reading Companion (chat nhiều lượt, thẻ truyện, tóm tắt On-Demand Cache-Aside chống spoil) và Agent 2 Integrity (lọc bình luận Regex + điểm toxic, shadowban, quét đạo văn SimHash 64-bit, Human-in-the-Loop). Giám sát từng lượt suy luận bằng Langfuse, nhúng iframe trên Admin.
  • Autonomous Webhook Top-up: Nạp xu tự động qua Webhook IPN, loại bỏ hoàn toàn duyệt tay thủ công và polling bên thứ ba.

Tên khóa bám schema đang chạy (story_id, chapter_id, chapter_no, user_id). Tiến độ đọc lấy từ reading_history.chapter_no, không thêm bảng tiến độ thứ hai.

3. Functional Requirements (FR)

A. Độc giả

  • FR-READER-08 (Sửa Search): Định tuyến GET /books/search đặt trước /:id, nối bảng đúng cột (cover_image, likes, views), lọc is_hidden = 0.

B. Agent 1 — Reading Companion (đồng bộ, giao diện chat)

  • FR-AGENT1-01 (Function calling): get_user_progress lấy reading_history.chapter_no làm chương hiện tại. get_catchup_summary chỉ được đọc chương nhỏ hơn chương hiện tại. search_stories dùng MySQL FULLTEXT (title, description). save_to_favorites thêm truyện vào tủ sách.
  • FR-AGENT1-02 (Cache-Aside chống spoil): Cửa sổ tóm tắt là from = max(1, current − 15) đến to = current − 1. Tra story_summary_cache theo (story_id, from_chapter, to_chapter). Cache miss thì lấy chapters.content trong khoảng đó, prompt cấm nhắc chương current trở đi, ghi ngược bản tóm tắt. Chương mở đầu (to < 1) trả lời không có sự kiện trước.
  • FR-AGENT1-03 (UI trên trình đọc): Nút nổi tự ẩn khi cuộn xuống. Bottom sheet chiếm khoảng 50% màn hình, không che cả trang đọc. Quick chip một chạm Tóm tắt 10 chương trước. Chat nhiều lượt trả lời kèm story card. Mỗi lượt assistant lưu messages.trace_id. 
async function getCatchUpSummary(storyId, currentChapter) {
  const toChapter = currentChapter - 1;
  if (toChapter < 1) return "Bạn đang ở chương mở đầu, chưa có sự kiện trước đó.";
  const fromChapter = Math.max(1, currentChapter - 15);

  const [cached] = await db.query(
    "SELECT summary_text FROM story_summary_cache WHERE story_id = ? AND from_chapter = ? AND to_chapter = ?",
    [storyId, fromChapter, toChapter]
  );
  if (cached.length > 0) return cached[0].summary_text;

  const [rawChapters] = await db.query(
    "SELECT chapter_no, content FROM chapters WHERE story_id = ? AND chapter_no BETWEEN ? AND ? ORDER BY chapter_no ASC",
    [storyId, fromChapter, toChapter]
  );

  const prompt = `Tóm tắt các tình tiết chính từ chương ${fromChapter} đến ${toChapter}. CẤM ĐỀ CẬP tình tiết từ chương ${currentChapter} trở đi.`;
  const summaryText = await callLLM(prompt, rawChapters);

  await db.query(
    "INSERT INTO story_summary_cache (story_id, from_chapter, to_chapter, summary_text) VALUES (?, ?, ?, ?)",
    [storyId, fromChapter, toChapter, summaryText]
  );
  return summaryText;
}

C. Agent 2 — Moderation & Integrity (bất đồng bộ, worker)

  • FR-AGENT2-01 (Lọc bình luận 2 tầng): Tầng 1 Regex chặn từ cực đoan và link cờ bạc trước khi ghi (dưới 1ms). Tầng 2 worker chấm điểm toxic. Điểm 0.5–0.8 đặt status = 'shadowbanned' (chỉ người viết thấy). Điểm trên 0.8 chuyển vùng đỏ, chờ admin khóa.
  • FR-AGENT2-02 (SimHash, không tốn token): Khi POST /books/:id/chapters, tính vân tay 64-bit lưu chapter_fingerprints.simhash_64. So Hamming distance với kho chương. D_H ≤ 3 (trùng khoảng ≥ 85%) thì giữ chương pending_review và ghi moderation_logs.
  • FR-AGENT2-03 (HITL): Vùng xanh tự xuất bản. Vùng vàng bắt buộc admin duyệt trên Diff Viewer hai cột. Vùng đỏ soft-block, admin xác nhận khóa chương hoặc tài khoản. Mỗi quyết định agent ghi trace_id.

D. Nạp xu tự động qua Webhook (Autonomous Webhook Top-up)

  • FR-PAY-01 (Tạo Intent nạp xu): POST /wallet/topup-intent sinh mã payment_code dạng NAPXU <USER_ID> <RANDOM>, lưu bản ghi topup_intents trạng thái pending (hạn 15 phút), trả về payload VietQR.
  • FR-PAY-02 (Xử lý Webhook IPN): POST /payments/webhook tiếp nhận callback từ cổng thanh toán tự động (SePAY / PayOS / Cassop). Xác thực chữ ký HMAC-SHA256 bí mật. Thực hiện khóa nguyên tử: 
    UPDATE topup_intents SET status='consumed' WHERE payment_code=? AND status='pending';
    Nếu thành công 1 hàng thì gọi creditWallet() và ghi audit payments. Bỏ hoàn toàn polling 5s và xóa luồng duyệt tay thủ công.
  • FR-PLAT-04 (Khóa lỗ hổng tiền tệ): Chặn quyền tự cộng xu/VIP: POST /wallet/topup, POST /users/:id/vip, POST /payments trả về 403 Forbidden nếu không phải Admin.
  • FR-PLAT-06 (Mua VIP): POST /wallet/buy-vip bỏ qua giá từ client, trừ đúng số xu quy định bởi biến môi trường VIP_COST_COINS (mặc định 500).

5. Data Model Changes (DDL Schema)

-- Bảng người dùng
CREATE TABLE IF NOT EXISTS users (
  user_id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  fullname VARCHAR(191) NULL,
  email VARCHAR(191) NOT NULL,
  password_hash VARCHAR(255) NULL,
  role VARCHAR(50) NOT NULL DEFAULT 'user',
  avatar_url VARCHAR(500) NULL,
  vip_until DATETIME NULL,
  firebase_uid VARCHAR(128) NULL,
  auth_method VARCHAR(20) NULL DEFAULT 'email',
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (user_id),
  UNIQUE KEY uk_users_email (email),
  UNIQUE KEY uk_users_firebase_uid (firebase_uid)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- Bảng ví tiền
CREATE TABLE IF NOT EXISTS wallets (
  wallet_id INT AUTO_INCREMENT PRIMARY KEY,
  user_id VARCHAR(191) UNIQUE,
  balance BIGINT DEFAULT 0,
  updated_at DATETIME
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- Bảng Intent nạp tiền tự động (có hạn dùng)
CREATE TABLE IF NOT EXISTS topup_intents (
  intent_id INT AUTO_INCREMENT PRIMARY KEY,
  user_id VARCHAR(191) NOT NULL,
  coins BIGINT NOT NULL,
  amount BIGINT NOT NULL,
  payment_code VARCHAR(191) NOT NULL,
  account_no VARCHAR(64) NOT NULL,
  status VARCHAR(32) NOT NULL DEFAULT 'pending',
  expires_at DATETIME NOT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_payment_code (payment_code),
  KEY idx_user_status (user_id, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- Full-text cho search_stories (Agent 1)
ALTER TABLE stories
  ADD FULLTEXT INDEX ft_story_search (title, description);

-- Trạng thái chương phục vụ HITL (Agent 2)
ALTER TABLE chapters
  ADD COLUMN status ENUM('draft', 'pending_review', 'published', 'rejected') NOT NULL DEFAULT 'published';

-- Cache tóm tắt theo khoảng chương (thay chapter_recaps từng chương)
CREATE TABLE IF NOT EXISTS story_summary_cache (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  story_id BIGINT UNSIGNED NOT NULL,
  from_chapter INT NOT NULL,
  to_chapter INT NOT NULL,
  summary_text TEXT NOT NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_story_range (story_id, from_chapter, to_chapter),
  KEY idx_summary_lookup (story_id, from_chapter, to_chapter),
  CONSTRAINT fk_cache_story FOREIGN KEY (story_id) REFERENCES stories (story_id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- Lịch sử chat và trace Langfuse (Agent 1)
CREATE TABLE IF NOT EXISTS conversations (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  user_id BIGINT UNSIGNED NULL,
  title VARCHAR(255) NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  CONSTRAINT fk_conv_user FOREIGN KEY (user_id) REFERENCES users (user_id) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS messages (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  conversation_id BIGINT UNSIGNED NOT NULL,
  sender ENUM('user', 'assistant') NOT NULL,
  content TEXT NOT NULL,
  metadata JSON NULL,
  trace_id VARCHAR(64) NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_conv_time (conversation_id, created_at),
  KEY idx_trace (trace_id),
  CONSTRAINT fk_msg_conv FOREIGN KEY (conversation_id) REFERENCES conversations (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- Bình luận: shadowban + điểm toxic (thay moderation_label / is_spoiler)
ALTER TABLE comments
  ADD COLUMN toxicity_score FLOAT NOT NULL DEFAULT 0,
  MODIFY COLUMN status ENUM('pending', 'approved', 'shadowbanned', 'rejected') NOT NULL DEFAULT 'approved';

-- Vân tay SimHash (thay plagiarism_checks theo embedding)
CREATE TABLE IF NOT EXISTS chapter_fingerprints (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  story_id BIGINT UNSIGNED NOT NULL,
  chapter_id BIGINT UNSIGNED NOT NULL,
  simhash_64 BIGINT UNSIGNED NOT NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_simhash (simhash_64),
  CONSTRAINT fk_fp_chapter FOREIGN KEY (chapter_id) REFERENCES chapters (chapter_id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- Hàng đợi Human-in-the-Loop
CREATE TABLE IF NOT EXISTS moderation_logs (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  target_type ENUM('comment', 'chapter') NOT NULL,
  target_id BIGINT UNSIGNED NOT NULL,
  violation_type ENUM('toxicity', 'spam', 'plagiarism') NOT NULL,
  confidence_score FLOAT NOT NULL,
  matched_target_id BIGINT UNSIGNED NULL,
  evidence_data JSON NULL,
  trace_id VARCHAR(64) NULL,
  status ENUM('pending_review', 'approved_by_admin', 'penalized_by_admin') NOT NULL DEFAULT 'pending_review',
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_mod_status (status, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
