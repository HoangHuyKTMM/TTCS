# Welcome character illustration

Asset: `src/assets/welcome-characters.png`

Generated with the built-in `image_gen` tool, using transparent output. The original output was copied into the project without altering its alpha channel. This illustration replaces the decorative book covers and their captions on the welcome screen.

The same image is used as the app logo, Android launcher icon and web favicon. `app.json` references the original asset directly. Run `node scripts/sync-app-icons.cjs` to regenerate icons in the existing Android project using Expo's icon generator, then rebuild the Android app. The separate five-second opening illustration remains in `src/assets/splash.png`.
