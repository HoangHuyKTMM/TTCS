Đặc Tả Kỹ Thuật Toàn Diện (Full Specification)

Hệ Thống Dual-Agent Nền Tảng Truyện

Kiến trúc Reading Companion & Integrity Agent vận hành trên 100% MySQL, cơ chế On-Demand Cache-Aside chống Spoil, kiểm duyệt SimHash và giám sát quan sát qua Langfuse Iframe.

2 Thiết Kế Cơ Sở Dữ Liệu MySQL (DDL Toàn Diện)

Được chuẩn hóa trên engine InnoDB, bộ mã utf8mb4_unicode_ci với đầy đủ khóa ngoại và đánh Index tối ưu hóa truy vấn.

-- ========================================================
-- 1. DỮ LIỆU TRUYỆN & NỘI DUNG CHƯƠNG
-- ========================================================
CREATE TABLE IF NOT EXISTS stories (
    id INT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    author VARCHAR(100),
    genres VARCHAR(255),
    status ENUM('ongoing', 'completed') DEFAULT 'ongoing',
    description TEXT,
    total_chapters INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FULLTEXT INDEX ft_story_search (title, description)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS chapters (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    story_id INT NOT NULL,
    chapter_number INT NOT NULL,
    title VARCHAR(255),
    content LONGTEXT NOT NULL,
    status ENUM('draft', 'pending_review', 'published', 'rejected') DEFAULT 'published',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_story_chapter (story_id, chapter_number),
    INDEX idx_story_num (story_id, chapter_number),
    CONSTRAINT fk_chapter_story FOREIGN KEY (story_id) REFERENCES stories(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ========================================================
-- 2. TIẾN ĐỘ NGƯỜI ĐỌC, CACHE TÓM TẮT & CHATBOT (AGENT 1)
-- ========================================================
CREATE TABLE IF NOT EXISTS user_reading_progress (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    story_id INT NOT NULL,
    current_chapter INT NOT NULL DEFAULT 1,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_user_story (user_id, story_id),
    CONSTRAINT fk_progress_story FOREIGN KEY (story_id) REFERENCES stories(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS story_summary_cache (
    id INT AUTO_INCREMENT PRIMARY KEY,
    story_id INT NOT NULL,
    from_chapter INT NOT NULL,
    to_chapter INT NOT NULL,
    summary_text TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_story_range (story_id, from_chapter, to_chapter),
    INDEX idx_summary_lookup (story_id, from_chapter, to_chapter),
    CONSTRAINT fk_cache_story FOREIGN KEY (story_id) REFERENCES stories(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS conversations (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NULL,
    title VARCHAR(255),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS messages (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    conversation_id INT NOT NULL,
    sender ENUM('user', 'assistant') NOT NULL,
    content TEXT NOT NULL,
    metadata JSON NULL,
    trace_id VARCHAR(64) NULL, -- Khóa logic liên kết Trace Langfuse
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_conv_time (conversation_id, created_at),
    INDEX idx_trace (trace_id),
    CONSTRAINT fk_msg_conv FOREIGN KEY (conversation_id) REFERENCES conversations(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ========================================================
-- 3. KIỂM DUYỆT BÌNH LUẬN, BẢN QUYỀN & HITL (AGENT 2)
-- ========================================================
CREATE TABLE IF NOT EXISTS comments (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    story_id INT NOT NULL,
    chapter_id BIGINT NULL,
    user_id INT NOT NULL,
    content TEXT NOT NULL,
    status ENUM('pending', 'approved', 'shadowbanned', 'rejected') DEFAULT 'approved',
    toxicity_score FLOAT DEFAULT 0.0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_comment_feed (story_id, status, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS chapter_fingerprints (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    story_id INT NOT NULL,
    chapter_id BIGINT NOT NULL,
    simhash_64 BIGINT UNSIGNED NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_simhash (simhash_64),
    CONSTRAINT fk_fp_chapter FOREIGN KEY (chapter_id) REFERENCES chapters(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS moderation_logs (
    id INT AUTO_INCREMENT PRIMARY KEY,
    target_type ENUM('comment', 'chapter') NOT NULL,
    target_id BIGINT NOT NULL,
    violation_type ENUM('toxicity', 'spam', 'plagiarism') NOT NULL,
    confidence_score FLOAT NOT NULL,
    matched_target_id BIGINT NULL,
    evidence_data JSON NULL,
    trace_id VARCHAR(64) NULL,
    status ENUM('pending_review', 'approved_by_admin', 'penalized_by_admin') DEFAULT 'pending_review',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_mod_status (status, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

3 Agent 1: Reading Companion & Cache-Aside

Bộ Công Cụ (Function Calling)

  • get_user_progress: Lấy current_chapter hiện tại.
  • get_catchup_summary: Ràng buộc an toàn: chặn lấy nội dung chương $\ge current\_chapter$.
  • search_stories: Tìm kiếm với MySQL Full-Text Search.
  • save_to_favorites: Thêm truyện vào tủ sách tự động.

Giao Diện Người Đọc (UI)

  • Floating Button: Nút nổi thông minh tự ẩn khi cuộn xuống.
  • Bottom Sheet: Ngăn trượt 50% màn hình, không che khuất trang đọc.
  • Quick Chips: Nút bấm 1 chạm "Tóm tắt 10 chương trước".
// Logic Tóm Tắt On-Demand Chống Spoil & Lưu Cache
async function getCatchUpSummary(storyId, currentChapter) {
  const toChapter = currentChapter - 1;
  if (toChapter < 1) return "Bạn đang ở chương mở đầu, chưa có sự kiện trước đó.";
  const fromChapter = Math.max(1, currentChapter - 15);

  // 1. Kiểm tra Cache MySQL
  const [cached] = await db.query(
    "SELECT summary_text FROM story_summary_cache WHERE story_id = ? AND from_chapter = ? AND to_chapter = ?",
    [storyId, fromChapter, toChapter]
  );
  if (cached.length > 0) return cached[0].summary_text;

  // 2. Cache Miss -> Lấy nội dung gốc an toàn
  const [rawChapters] = await db.query(
    "SELECT chapter_number, content FROM chapters WHERE story_id = ? AND chapter_number BETWEEN ? AND ? ORDER BY chapter_number ASC",
    [storyId, fromChapter, toChapter]
  );

  // 3. Prompting cô lập Spoil
  const prompt = `Tóm tắt các tình tiết chính từ chương ${fromChapter} đến ${toChapter}. CẤM ĐỀ CẬP tình tiết từ chương ${currentChapter} trở đi.`;
  const summaryText = await callLLM(prompt, rawChapters);

  // 4. Ghi ngược vào Cache
  await db.query(
    "INSERT INTO story_summary_cache (story_id, from_chapter, to_chapter, summary_text) VALUES (?, ?, ?, ?)",
    [storyId, fromChapter, toChapter, summaryText]
  );

  return summaryText;
}

4 Agent 2: Moderation & Integrity (Bản Quyền & Shadowban)

1. Luồng Lọc Bình Luận

Kết hợp Regex tức thì với chấm điểm Toxic bất đồng bộ

  1. Tầng 1 (Regex): Chặn từ khóa cực đoan, link cờ bạc (thời gian < 1ms).
  2. Tầng 2 (AI Worker): Chấm điểm độc hại ngầm qua Queue.
  3. Shadowban: Độc hại từ 0.5 - 0.8 thì ẩn tàng hình (chỉ người viết thấy).

2. Kiểm Duyệt Đạo Văn (SimHash)

0 token AI tiêu thụ, xử lý hàng nghìn chương cực nhanh

  1. Tạo vân tay: Tính mã băm nhị phân 64-bit cho chương mới tải lên.
  2. Hamming Distance: So khớp số bit khác nhau $D_H$ với kho truyện.
  3. Gắn cờ: $D_H \le 3$ (Trùng khớp $\ge 85\%$) $\rightarrow$ Tạm giữ trạng thái và báo Admin.

5 Mô Hình Phân Cấp Human-In-The-Loop (HITL)

Phân Vùng Tiêu Chuẩn Rủi Ro Hành Động Tự Động Của Agent Can Thiệp Của Admin
Vùng Xanh Trùng lặp < 50% / Toxic < 0.5 Phê duyệt và xuất bản công khai ngay. Không cần can thiệp.
Vùng Vàng Trùng lặp 50% - 85% / Toxic 0.5 - 0.8 Chuyển pending_review, đẩy vào log. Bắt buộc duyệt trên Diff Viewer.
Vùng Đỏ Trùng lặp > 85% / Toxic > 0.8 Tự động tạm khóa (Soft Block), cảnh báo đỏ. Xác nhận chế tài khóa truyện/tài khoản.
